# Муха в проводах

Интерактивный экспонат для фестиваля науки (0+): симуляция мозга дрозофилы
на реальном коннектоме FlyWire 783. Всё работает без интернета и без сервера —
страницы открываются двойным кликом.

## Что открывать

| файл | для чего |
|---|---|
| `stand/screen.html` + `stand/control.html` | **два экрана**: на большом — мозг и муха, на втором — пульт |
| `stand/big.html` | один большой монитор, кнопки внизу экрана |
| `stand/index.html` | ноутбук, крупные кнопки |
| `arcade/index.html` | игра «Успей за мухой» (старт как в Формуле 1) |

Браузер — Chrome или Edge, полный экран — **F11**.

### Два экрана
1. Открыть `stand/screen.html`, перетащить окно на большой монитор, F11.
2. Нажать **P** (или «пульт» в карточке слева) — откроется окно пульта.
   Перетащить его на второй экран, F11.
3. Индикатор в углу пульта «экран на связи» — всё готово.

Если пульт открыт отдельно двойным кликом по `control.html`, он тоже работает
(через localStorage того же браузера).

### Управление
| клавиша | действие |
|---|---|
| 1 2 3 | сахар, горькое, вода |
| 4 5 6 | тень, запах, касание |
| 0 | сломать нейрон / починить |
| + / − / R | приблизить / отдалить / сбросить вид |
| P | открыть пульт (на экране) |

Мозг можно крутить мышью или пальцем, колесо или щипок — приблизить,
правая кнопка или Shift — сдвинуть, двойной клик — сбросить. Через 40 с без
касаний вид возвращается сам.

### Если тормозит
Добавить к адресу `?lite`, например `stand/screen.html?lite` — без цветного
«клубка» связей, остаются только цепи сигнала.

## Как устроено

- `src/` — Python: распаковка данных, LIF-модель (Shiu et al. 2024) на NumPy,
  сценарии по 1 с, подбор ключевого нейрона для поломки, экспорт для стенда.
  Порядок: `find_inputs.py` → `scenarios.py` → `export.py`; `escape.py` — для аркады.
- `data/raw/` — данные FlyWire (CC-BY 4.0), `data/export/fly_data.js` — всё для стенда.
- `stand/`, `arcade/`, `shared/` — vanilla JS, three.js r149 лежит в `stand/vendor/`.

Цветной «клубок» на карте — это связи из коннектома (по две самые сильные на
нейрон), а не форма отростков: формы отростков в этих данных нет.

## Источники (вынести на стенд)

- Связи и координаты нейронов — FlyWire, выпуск 783 (Dorkenwald et al.; Schlegel et al.), CC-BY 4.0.
- Аннотации типов клеток — github.com/flyconnectome/flywire_annotations.
- Модель и списки вкусовых нейронов — Shiu et al. 2024, github.com/philshiu/Drosophila_brain_model.
- Упакованные файлы данных — github.com/RaphaelSR/fly-brain-bench (CC-BY 4.0).
- Взлёт через гигантское волокно — von Reyn et al. 2014; Chai et al. 2025.
- three.js (MIT), шрифт Manrope (SIL OFL 1.1).
